## 3. 상태 체계: 확정상태 + 장중상태 + 행동

### 3.1 확정상태

최근 완료 정규장 기준의 공식 상태이다.

`M0 / M1 / M2 / W / S1 / S2 / S3`

Wiki의 장기 이력과 Revision Timeline의 기준 상태로 사용한다.

### 3.2 장중상태

현재 정규장이 진행 중이면 장중 가격·거래량을 적극 반영하여 별도의 **잠정상태(provisional)** 를 산출한다.

표기:

- `P-M1`, `P-M2`
- `P-W`
- `P-S1`, `P-S2`, `P-S3`

장중상태는 완료장 확정상태를 임의로 덮어쓰지 않는다. 종가 후 조건이 유지되면 다음 완료장 분석에서 공식 상태로 승격한다.

### 3.3 현재 행동

실제 사용자에게 제시하는 행동지시는 **확정상태만이 아니라 장중상태까지 반영**한다.

특히 매도 쪽은 거래량 폭증이 장중에 이미 확인되면 종가까지 기다리지 않고 `분할매도 검토` 또는 `과열 매도 검토`를 제시할 수 있다.

즉:

`확정상태 = 기록 기준`

`장중상태 = 실시간 경보 기준`

`현재 행동 = 확정상태 + 장중상태 + 기업위험의 종합판정`

## 5. 장중 거래량 보정

장중 거래량을 완료장 일평균 거래량과 단순 비교하지 않는다.

### 5.1 최우선 방식: 동시간대 거래량 배율

가능하면 다음을 사용한다.

`동시간대 거래량 배율 = 현재 누적거래량 ÷ 최근 20거래일 동일 시각까지의 평균 누적거래량`

예:

- 최근 20일 12:30 평균 누적거래량 = 100,000주
- 금일 12:30 누적거래량 = 600,000주

→ 동시간대 거래량 배율 = `6.0배`

이 경우 종가 전이라도 거래량 폭증으로 판정할 수 있다.

### 5.2 차선 방식: 시간대별 누적비율 보정

동일 시각 과거 누적거래량이 직접 없으면, 최근 20일의 평균 장중 거래량 프로파일을 이용한다.

`예상 종가 거래량 = 현재 누적거래량 ÷ 과거 평균 동일시각 누적비율`

`예상 종가 거래량 배율 = 예상 종가 거래량 ÷ 20일 평균 일거래량`

예를 들어 과거 평균적으로 12:30까지 하루 거래량의 45%가 체결된다면 현재 누적거래량을 0.45로 나누어 종가 예상 거래량을 계산한다.

### 5.3 최후 방식

동시간대 자료와 시간대 프로파일을 모두 구할 수 없으면:

`현재 누적거래량 ÷ 20일 평균 일거래량`

은 **하한 확인용 참고값**으로만 사용한다. 이를 그대로 장중 거래량 배율이라고 부르지 않는다.

단순 경과시간 비례 선형 환산은 개장·마감 거래량 집중 때문에 기본 방식으로 사용하지 않는다.

## 7. 매입 판정

### 7.1 완료장 기반 기본조건

1. 최근 의미 있는 고점 대비 충분한 가격 조정
2. 최근 거래량이 20일·60일 평균 대비 현저히 감소
3. 거래량 감소가 여러 거래일 지속
4. 10~20거래일 신저가 갱신 중단 또는 하락 속도 둔화
5. 기업 존속·자금조달·상장 등 구조적 위험 악화 없음

정량 참고값:

- 거래량 고갈 후보: 최근 거래량이 60일 평균의 약 `30~40% 이하`
- 가격 위치: 최근 주요 고점 대비 약 `-30% 이상 조정` 우선
- 바닥 확인: `10~20거래일` 신저가 갱신 중단

### 7.2 장중 매입 보정

장중 거래량이 적다는 이유만으로 M1/M2를 새로 만들지 않는다. 거래량 고갈은 여러 완료장의 누적 현상이어야 한다.

다만 기존 확정상태가 M1이면 다음 장중 조건을 이용해 `P-M2` 가능성을 판단한다.

- 전일·최근 저점을 깨지 않음
- 장중 저점 형성 후 회복
- 매도압력 감소
- 거래량이 비정상 폭증하지 않음
- 가격이 장중 저점 대비 회복하고 유지

이 경우 현재 행동을 `분할매입 후보 실행 검토`로 높일 수 있다.

### 7.3 분할매입

- 1차: 완료장 거래량 고갈 확인
- 2차: 완료장 또는 장중 바닥 유지 확인
- 3차: 거래량 회복과 상승 전환 확인

무제한 물타기는 금지한다.

## 8. 매도 판정

### 8.1 장중 매도는 적극 반영

순환매 전략의 핵심은 거래량 폭증 시 청산이므로 장중 매도 신호는 완료장을 기다리지 않고 적극 반영한다.

### 8.2 P-S1

- 동시간대 거래량 배율이 평시보다 의미 있게 상승
- 가격 반등 또는 갭 상승 시작

→ `신규매입 금지 / 매도 준비`

### 8.3 P-S2

기본 참고값:

`동시간대 거래량 배율 또는 보정 예상 종가 거래량 배율 ≥ 약 4~5배`

＋

`주가 급등 또는 갭 상승`

→ `보유분 분할매도 검토`

### 8.4 P-S3

다음 중 하나 이상이면 장중 과열 경보를 낸다.

- 보정 거래량 배율 약 `8~10배 이상`
- 장대양봉 후 긴 윗꼬리
- 장중 고점 대비 급격한 밀림
- 갭 급등 후 상승 탄력 소멸
- 거래량 폭증에도 추가 상승 실패
- 뉴스·테마가 시장 전체에 과도하게 확산

→ `대부분 또는 전량매도 우선 검토`

장중 P-S2/P-S3가 종가까지 유지되지 않아도 당시 행동판단 기록은 삭제하지 않는다. 종가 후 공식 상태와 다르면 Revision Timeline에 `INTRADAY_REVERSAL` 또는 `NOT_CONFIRMED_AT_CLOSE`로 기록할 수 있다.

## 11. 한 줄 행동지시

`거래량-순환매-Wiki.md`의 `1.2 현재 순환 순서`와 재질의 답변에는 반드시 한 줄 행동지시를 둔다.

행동지시는 **현재 행동 기준**으로 작성하므로 장중상태가 있으면 이를 반영한다.

기본 형식:

`**한줄 행동지시:** 현재 [매입 우선종목]은 [행동]하고, [매도 우선종목]은 [행동]하라.`

상태별 기본 동사:

- `M1` → `분할매입 후보로 우선 검토하라`
- `M2` 또는 신뢰도 높은 `P-M2` → `분할매입을 실행 검토하라`
- `W/M0` → 매입 대상으로 지목하지 않음
- `S1/P-S1` → `신규매입하지 말고 매도를 준비하라`
- `S2/P-S2` → `보유분을 분할매도하라`
- `S3/P-S3` → `대부분 또는 전량매도를 우선 검토하라`

장중 P 상태는 한 줄에 `(장중 잠정)`을 붙여 확정상태와 혼동하지 않게 한다.

예:

`**한줄 행동지시:** 현재 스페코는 분할매입을 실행 검토하고(장중 P-M2), UAVS는 보유분을 분할매도하라(장중 P-S2).`

상태보다 강한 확정 표현으로 자동 승격하지 않는다.

- 전략 규칙

### 12.2 장중상태 변경

장중 P-M2/P-S1/P-S2/P-S3처럼 **실제 행동을 바꿀 정도의 잠정신호**가 발생하면 Wiki의 `Intraday View`를 갱신할 수 있다.

단순한 장중 등락이나 소폭 거래량 변화는 저장하지 않는다.

장중 기록에는 다음을 포함한다.

- `intraday_timestamp`
- `intraday_state`
- `confirmed_state_before_open`
- `current_price`
- `intraday_volume`
- `intraday_volume_ratio`
- `ratio_method`
- `action`
- `reason`

종가 후에는 Intraday View를 다음 중 하나로 정리한다.

- `CONFIRMED_AT_CLOSE`
- `PARTIALLY_CONFIRMED`
- `NOT_CONFIRMED_AT_CLOSE`

### 12.3 Revision Timeline

의미 있는 변경만 append한다.

- `revision_id`: `YYYYMMDD-NN`
- `analysis_date`
- `latest_complete_session`
- `change_type`
- `changed_stocks`
- `previous_state`
- `new_state`
- `source_summary`
- `reason`

과거 기록은 삭제·수정하지 않는다.

GitHub write 성공 전에는 `Wiki 갱신 완료`라고 표현하지 않는다.
